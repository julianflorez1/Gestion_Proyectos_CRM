## 🧩 Descripción General

Este repositorio contiene la documentación completa del proyecto académico de gestión de proyectos enfocado en la evaluación, planificación y propuesta de implementación de un sistema CRM (*Customer Relationship Management*).

El objetivo principal del proyecto es analizar la necesidad de una solución CRM para una organización, definir el alcance del proyecto, evaluar proveedores, identificar riesgos y establecer responsabilidades para una implementación efectiva y sostenible.

---

## 📁 Contenido del Repositorio

A continuación se presenta la guía basada en los nombres reales de los archivos almacenados en este repositorio:

- `Lean Business Case - CRM.docx`  
  Documento de caso de negocio Lean para justificar la inversión en la solución CRM, incluyendo beneficios esperados, viabilidad y análisis de valor.

- `Analisis_de Gartner_CRM.pdf`  
  Estudio de mercado y análisis de tendencias basado en referencias de Gartner sobre soluciones CRM.

- `Especificaciones del Proyecto de CRM.xlsx`  
  Documento con requisitos funcionales, no funcionales, especificaciones técnicas y criterios de validación del proyecto.

- `Calificación de proveedores CRM.xlsx`  
  Matriz de evaluación de proveedores CRM, comparativa de opciones y criterios de selección.

- `Alcance de las integraciones.docx`  
  Documento que define los alcances, dependencias e integraciones del CRM con otros sistemas de la organización.

- `Matriz_RACI_Implementacion_CRM.xlsx`  
  Matriz RACI que organiza responsabilidades, roles y niveles de participación del equipo del proyecto.

- `Riesgos CRM Mapa de Calor.xlsx`  
  Identificación y priorización de riesgos con análisis de impacto, probabilidad y estrategias de mitigación.

---

## 🎯 Objetivos del Proyecto

- Definir la necesidad de una solución CRM para la organización.
- Analizar el mercado y comparar alternativas disponibles.
- Establecer el alcance técnico y funcional del proyecto.
- Evaluar proveedores con criterios objetivos.
- Diseñar la estructura de trabajo del proyecto.
- Identificar y mitigar riesgos.
- Presentar una propuesta técnica y de negocio sustentada.

## 🧭 Guía de Uso

1. Revisar `Lean Business Case - CRM.docx` para comprender la justificación y viabilidad del proyecto.
2. Leer `Analisis_de Gartner_CRM.pdf` para conocer el contexto del mercado CRM.
3. Consultar `Especificaciones del Proyecto de CRM.xlsx` para entender requisitos y alcance.
4. Revisar `Calificación de proveedores CRM.xlsx` para analizar las alternativas.
5. Ver `Alcance de las integraciones.docx` para estudiar dependencias y conectividad prevista.
6. Revisar `Matriz_RACI_Implementacion_CRM.xlsx` para identificar responsabilidades del equipo.
7. Evaluar `Riesgos CRM Mapa de Calor.xlsx` para anticipar amenazas y planificar mitigaciones.

## 👥 Roles y Responsabilidades

El proyecto contempla una estructura básica de roles para la gestión del esfuerzo de implementación:

- Líder del Proyecto
- Analista de Negocio
- Analista de Requisitos
- Evaluador de Proveedores
- Responsable de Integraciones
- Responsable de Riesgos
- Equipo de Implementación

Estas responsabilidades están formalizadas en la matriz RACI del proyecto.
